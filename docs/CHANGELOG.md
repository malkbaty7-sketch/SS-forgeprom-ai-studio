# سجل التغييرات

## v1.2.0 — versionCode 4 (2026-11-20)

جاهزية تشغيلية للبوابة، وتقوية أمان التطبيق، وقوالب بداية، وشفافية الاستهلاك.

### أُضيف

- **فحص جاهزية البوابة `/readyz`:** يتحقق من إعداد المزوّد ومن الوصول إلى قاعدة الحصص، ويعيد 200/503 بأسماء الفحوص فقط دون أي قيم إعدادات أو رسائل أخطاء.
- **معرّفات طلبات وسجلات منظمة:** كل استجابة تحمل `X-Request-Id` (تُعاد القيمة الصالحة أو يُولّد UUID)، وسجل JSON لكل طلب يتضمن الحالة والمدة ومعرّف الحساب بعد المصادقة، دون رموز أو رؤوس أو نصوص رسائل.
- **إغلاق لطيف:** `SIGTERM`/`SIGINT` يوقفان القبول ويُمنح الطلب الجاري حتى 10 ثوانٍ، مع خروج بالرمز 1 عند تجاوز المهلة بدل التعليق. وحدود زمنية صريحة للاتصالات.
- **حاوية تشغيل:** `Dockerfile` بمستخدم غير جذر وفحص صحة عبر `/readyz`، و`compose.yaml` ينشر على المضيف المحلي فقط، و`.env.example`، و`HOST` قابل للضبط.
- **اختبارات البوابة في CI:** سير عمل مستقل يشغّل `npm test` ويبني صورة Docker عند أي تغيير في مجلد الخدمة.
- **سياسة HTTPS:** رفض العناوين غير المشفرة في الإعدادات (باستثناء localhost و10.0.2.2 للتطوير)، و`network_security_config` يمنع النص الواضح افتراضياً.
- **قيود النسخ الاحتياطي للنظام:** استثناء قاعدة المشاريع والمفاتيح المشفرة والمسودات من النسخ السحابي والانتقال بين الأجهزة، مع بقاء التصدير الصريح بيد المستخدم.
- **بطاقة استهلاك البوابة:** إجمالي الطلبات ورموز الإدخال/الإخراج لآخر 30 يوماً وتوزيع النماذج، من `/v1/usage` بعد الموافقة وتهيئة الحساب.
- **قوالب بداية:** ستة قوالب (متجر، لوحة تحكم، صفحة هبوط، لعبة، مصادقة، إصلاح خطأ) تملأ الفكرة والهدف والتقنية ثم تُحرّر بحرية.

### الاختبارات

- ١٢ اختباراً جديداً لطبقة Kotlin (سياسة العنوان، تجميع الاستهلاك، القوالب) — إجمالي الاختبارات النقية ٣٠.
- ٦ اختبارات جديدة للبوابة (الجاهزية، معرّفات الطلبات، السجلات، الإغلاق) — إجمالي اختبارات الخدمة ٢٠.

### قيود معلنة

- `/readyz` لا يتحقق من صلاحية مفتاح المزوّد لدى المزود نفسه، بل من وجود إعداداته ومن الوصول إلى قاعدة الحصص.
- بطاقة الاستهلاك تعتمد على تفعيل `ENABLE_USAGE` في البوابة، وهي مراقبة لا فوترة.
- القوالب نصوص بداية محلية؛ لا تُرسل إلى أي خدمة قبل موافقتك المعتادة.

## v1.1.0 — versionCode 3 (2026-11-20)

تحسينات موثوقية تجربة الاستخدام: لا تفقد عملك، وابحث في مشاريعك، واحتفظ بنسخة منه.

### أُضيف

- **حفظ تلقائي واسترداد المسودات:** يحفظ المحرر العنوان والنص محلياً بعد توقف الكتابة ١٫٥ ثانية، ويعرض شريط «مسودة محلية غير محفوظة» عند إعادة فتح الموجّه مع خياري الاستعادة والتجاهل. زر الحفظ النهائي يمسح المسودة، والخروج بتعديلات يطلب تأكيداً.
- **بحث عربي مطبَّع في المشاريع:** يتجاهل التشكيل والتطويل ويوحّد الألف والياء والتاء المربوطة، ويبحث في الاسم والوصف والوسوم.
- **تصفية المشاريع:** الكل / المثبتة / المؤرشفة، ووسوم قابلة للنقر مع عدّاد نتائج ومسح فوري للفلاتر.
- **إدارة الوسوم:** حقل وسوم في نموذج المشروع (حتى ١٢ وسماً، مفصولة بفاصلة أو فاصلة عربية) وتخزين موحّد ومنع تكرار.
- **نسخ احتياطي واستعادة محلية:** تصدير JSON كامل للمشاريع والموجّات والتحليلات وملفات المحرر وتحليلات الصور عبر منتقي ملفات النظام (بلا إذن تخزين)، واستعادة **دمجية** لا تحذف شيئاً، مع تجاهل المشاريع الموجودة مسبقاً وإعادة ربط المعرّفات.
- شاشة «النسخ الاحتياطي والاستعادة» في الإعدادات، ومسجَّلة في سجل الميزات الصادق (R14).

### الاختبارات

- اختبارات جديدة: تطبيع البحث العربي، الوسوم، أنماط التصفية، ترميز المسودات، وترميز/فك النسخ الاحتياطي مع رفض الملفات غير الصالحة والإصدارات غير المدعومة والحقول الضخمة.

### قيود معلنة

- الاستعادة دمج فقط؛ لا توجد استعادة استبدالية أو حلّ تعارضات يدوي.
- المسودة محلية على الجهاز ولا تُزامن بين الأجهزة، وتُمسح بعد الحفظ النهائي.
- لا يشمل ملف النسخ الاحتياطي مفاتيح API ولا إعدادات الجهاز ولا المسودات غير المحفوظة.

## v1.0.0-mvp — versionCode 2 (2026-11-09)

النسخة الأولى القابلة للاستخدام.

### أُضيف

- تحليل الفكرة العربية محلياً: نية (11 نوعاً)، ميزات، متطلبات، قيود، افتراضات معلنة، أسئلة ≤3.
- مولد برومبتات 12 قسماً بثلاث لغات (عربي/إنجليزي/ثنائي) مع قيود منع التضخم.
- فحص جودة 14 عنصراً (خصم 7 لكل ناقص) + إصلاح تلقائي عند <70.
- النقد والاقتراح: نقاط قوة/نواقص/مخاطر/اقتراحات.
- إدارة مشاريع Room كاملة (إنشاء/تثبيت/أرشفة/حذف) + سجل نشاطات.
- محرر موجزات بعدادات كلمات/أحرف وحفظ ونسخ وتصدير.
- تصدير TXT/MD/JSON عبر FileProvider + مشاركة + نسخ حافظة (UTF-8).
- محرك محلي قاعدي يعمل دون إنترنت (ويرث فلسفة محرك v9.1).
- محركات سحابية اختيارية: Gemini 2.0 Flash (+Vision للصور) ومتوافق OpenAI — خلف بوابة موافقة صريحة.
- تحليل صور الواجهات: إقرار «استلهام فقط» + حد 5MB + ثقة وافتراضات معلنة.
- مفاتيح API مشفّرة (EncryptedSharedPreferences).
- سجل ميزات صادق (FeatureRegistry) وحول التطبيق.
- 8 اختبارات وحدة لطبقة المجال + سير عمل CI يبني APK تلقائياً.

- تحليل الصور سحابي فقط (Gemini) — لا تحليل محلي للصور.
- تشغيل الكود داخل المحرر مؤجل بدواعٍ أمنية.
