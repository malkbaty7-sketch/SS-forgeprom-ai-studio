# Forgeprom Code Studio

**استوديو عربي لصياغة الموجزات (البرومبتات) الهندسية الاحترافية** — حوّل فكرتك العربية الحرة إلى موجه هندسي كامل جاهز للنسخ في منصات بناء الكود (Claude، ChatGPT، Cursor، Replit…).

تطبيق **Android أصلي** (Kotlin + Jetpack Compose + Material 3)، يعمل **محلياً دون إنترنت** بمحرك قاعدي عربي، مع محركات سحابية **اختيارية بموافقة صريحة**.

## البدء السريع

```bash
git clone https://github.com/malkbaty7-sketch/forgeprom-app.git
cd forgeprom-app
gradle assembleDebug     # أو افتح المشروع في Android Studio (JDK 17)
```

- متطلبات البناء: JDK 17، Gradle 8.9، AGP 8.5.2، Kotlin 2.0.20، compileSdk 35، minSdk 26.
- الخرج: `app/build/outputs/apk/debug/app-debug.apk`.
- الاختبارات: `gradle testDebugUnitTest` (اختبارات طبقة المجال + البحث/التصفية + ترميز المسودات والنسخ الاحتياطي).

## البناء التلقائي (CI)

يرفع كل دفعة إلى `main` إلى سير عمل GitHub Actions (`.github/workflows/android.yml`):
1. `testDebugUnitTest` — اختبارات طبقة المجال.
2. `assembleDebug` — بناء APK.
3. رفع الناتج كـ artifact باسم **forgeprom-debug-apk** — نزّله من تبويب Actions.

وسير عمل مستقل (`.github/workflows/gateway.yml`) يشغّل اختبارات بوابة الخدمة (`npm test`) ويبني صورة Docker عند أي تغيير في `services/ai-gateway`.

## البنية

- `domain/` — محلل الأفكار، مولد البرومبت، فحص الجودة، النقد (Kotlin نقي قابل للاختبار).
- `core/` — المحركات (محلي قاعدي + Gemini + متوافق OpenAI)، Room، الإعدادات، مفاتيح مشفّرة، التصدير، مسودات المحرر، النسخ الاحتياطي.
- `ui/` — Compose: شاشات الرئيسية/التوليد/التحليل/النتيجة/الصور/المشاريع/المحرر/المحركات/الإعدادات/النسخ الاحتياطي.
- `docs/` — الخطة، PRD، المعمارية، سجل التغييرات.

## الخصوصية

- كل شيء يعمل محلياً افتراضياً (المحرك القاعدي لا يحتاج إنترنت).
- مفاتيح API تُحفظ مشفّرة (EncryptedSharedPreferences).
- أي استدعاء سحابي (Gemini / OpenAI) محجوب خلف بوابة موافقة صريحة.
- HTTPS إلزامي لكل المزودين، و`HTTP` مسموح فقط للتطوير المحلي على `localhost` أو `10.0.2.2`.
- قاعدة المشاريع والمفاتيح المشفرة والمسودات مستثناة من النسخ الاحتياطي السحابي للنظام؛ التصدير الصريح هو طريقك للنسخ.

### الحفظ التلقائي والبحث والنسخ الاحتياطي

- **الحفظ التلقائي:** بعد توقف الكتابة ١٫٥ ثانية يحفظ المحرر العنوان والنص كمسودة محلية. عند إعادة فتح الموجّه، يظهر شريط «مسودة محلية غير محفوظة» مع **استعادة المسودة** أو **تجاهل المسودة**. المسودة لا تغيّر الموجّه المحفوظ؛ لذلك يبقى زر **حفظ** هو الإجراء النهائي، ويمسح المسودة عند نجاحه. الخروج بتعديلات غير محفوظة يطلب تأكيداً.
- **البحث والتصفية:** شاشة المشاريع تبحث في الاسم والوصف والوسوم بتطبيع عربي (يتجاهل التشكيل ويوحّد الألف والياء والتاء المربوطة)، وتوفّر تصفية الكل/المثبتة/المؤرشفة ووسوماً قابلة للنقر وعدّاد نتائج. الوسوم تُدخل في نموذج المشروع مفصولة بفاصلة أو فاصلة عربية (حتى ١٢ وسماً) وتُخزَّن موحّدة بلا تكرار.
- **النسخ الاحتياطي:** من الإعدادات ← **النسخ الاحتياطي والاستعادة** صدّر ملف JSON كامل المشاريع والموجّات والتحليلات وملفات المحرر وتحليلات الصور. التصدير والاستعادة يمران عبر منتقي ملفات النظام فلا يحتاج التطبيق إذن تخزين. الاستعادة **دمج فقط**: لا تحذف شيئاً، وتتجاهل المشروع الموجود مسبقاً (نفس الاسم وتاريخ الإنشاء) مع ملحقاته، وتعيد ربط معرّفات الموجّات بالمشاريع الجديدة. لا يحتوي الملف مفاتيح API ولا إعدادات الجهاز ولا المسودات غير المحفوظة.

### القوالب والاستهلاك والأمان

- **قوالب البداية:** في شاشة الإنشاء، اختر «متجر إلكتروني» أو «لوحة تحكم» أو «صفحة هبوط» أو «لعبة ألغاز» أو «ميزة تسجيل دخول» أو «إصلاح خطأ» لتُملأ الفكرة والهدف والتقنية، ثم عدّل النص بحرية. القوالب محلية ولا تُرسل لأي خدمة.
- **استهلاك البوابة:** في الإعدادات، بطاقة «استهلاك البوابة (آخر ٣٠ يوماً)» تعرض الطلبات ورموز الإدخال/الإخراج وتوزيع النماذج من `/v1/usage`. تتطلب الموافقة السحابية ورمز حساب مهيّأً، وتعمل فقط إذا فعّل مشغّل البوابة `ENABLE_USAGE`. هذه مراقبة لا فاتورة.
- **الأمان:** يُرفض أي عنوان مزود غير مشفّر عند الحفظ (عدا التطوير المحلي)، ويتولى `network_security_config` منع النص الواضح على مستوى النظام. تُستثنى قاعدة البيانات والمفاتيح المشفرة والمسودات من النسخ الاحتياطي السحابي، ويبقى تصدير JSON الصريح متاحاً.

### تجربة المخرج التفاعلي (MVP)

من محرر موجه محفوظ، ظلّل جزءاً من النص واضغط **تعديل ذكي**. اكتب توجيهاً مثل «أضف صوت المطر»، وراجع الاقتراح قبل تطبيقه على التحديد فقط. لا يُحفظ التغيير في المشروع حتى تضغط **حفظ**.

تتطلب التجربة تفعيل الموافقة السحابية من الإعدادات، وضبط Gemini أو مزوّد OpenAI-compatible جاهز كمحرك للتوليد العام من شاشة النماذج. لا يرسل التطبيق عنوان الموجه. السياق المحيط معطّل افتراضياً؛ عند تفعيله يُعرض ما سيُرسل، بحد أقصى 400 وحدة UTF-16 لكل جانب. لا يتوفر توليد بديل بالمحرك المحلي.

لاختبار التجربة يدوياً: جرّب الطلب دون موافقة، ثم بعد تهيئة مزوّد سحابي؛ تحقّق من أن الإلغاء لا يغيّر النص وأن التطبيق يستبدل التحديد فقط، ثم احفظ وأعد فتح المحرر. اختبارات طبقة المجال: `gradle testDebugUnitTest`.

تتضمن نافذة التعديل إجراءات جاهزة للغضب ووجهة النظر والصوت والاختصار وتوسيع الحوار. اختيار الإجراء يملأ التوجيه فقط؛ يمكنك تعديله قبل الإرسال. تعرض المعاينة النص الأصلي والمقترح كاملين، ويمكنك الرجوع لتعديل التوجيه دون تغيير المستند.

إذا فشل طلب التعديل، يمكنك إعادة المحاولة بالتوجيه نفسه. بعد تطبيق الاقتراح، يعيد زر **تراجع عن التعديل الذكي** النص والتحديد السابقين ما دمت لم تعدّل النص يدوياً أو تغادر المحرر.

### توليد مشهد وذاكرة القصة المحلية

في محرر موجه محفوظ، افتح **توليد مشهد وذاكرة القصة**. اكتب وصفاً للمشهد، وأضف ملاحظات الشخصيات أو الأحداث يدوياً. زر حفظ الملاحظات يخزنها على الجهاز لهذا الموجه؛ لحذفها امسح الحقل واحفظه. لا تُرفق الملاحظات بطلب التوليد إلا عند اختيار إرسالها، ولا يُرسل محتوى المحرر. اختر نموذجًا عصبيًا محليًا مثبّتًا للتوليد دون اتصال، أو فعّل الموافقة السحابية واختر مزوّدًا جاهزًا.

بعد التوليد، راجع المشهد ثم شاركه بصيغة `.fountain` أو ألحقه بنهاية المحرر. الإلحاق قابل للتراجع قبل التعديل اليدوي، ولا يُحفظ المستند إلا عبر زر **حفظ**. يتحقق التطبيق مبدئياً من عنوان المشهد ووجود محتوى ومن عدم وجود أسوار Markdown؛ لا يجري تحققاً شاملاً من صيغة Fountain. لا يشمل هذا الإصدار استيراد الكتب، أو الاسترجاع الدلالي.

يدعم العرض أيضاً تصدير **FDX** للمشهد المولّد. يحوّل المصدّر عنوان المشهد والوصف وأسماء الشخصيات وإشارات الأداء والحوار إلى فقرات XML؛ لا يدعم كل امتدادات Fountain أو خصائص مستندات Final Draft الكاملة.

يتوفر كذلك PDF نصي للمشهد من المعاينة، مع التفاف الأسطر وتعدد الصفحات باستخدام محرك النص في Android.

تتضمن نافذة التوليد لوحة مصغرة لضبط الإيقاع والجو وتوجيهات الكاميرا والصوت. من المعاينة يمكنك حفظ نسخة محلية صراحةً؛ يحتفظ السجل بآخر خمس مسودات محفوظة لهذا الموجّه ويمكن إعادة فتحها أو مسح السجل. هذا ليس سجل مراجعات تلقائياً للمستند.

تشمل لوحة المخرج أيضاً اختيار أسلوب الإخراج والإضاءة وتفعيل إشارات الأداء. تُطبّق هذه الخيارات على مسودة السيناريو التالية ولا تغيّر أي مسودة محفوظة.

قبل التوليد، اختر صيغة المشهد: **سيناريو** (Fountain وFDX)، أو **سرد سينمائي**، أو **قائمة لقطات** (TXT). يتوفر PDF للثلاثة. تُحفظ المسودات بصيغتها النصية في السجل المحلي.

يُحفظ آخر خمسة مخرجات مختلفة تلقائياً لهذا الموجّه عند نجاح التوليد، ويمكن تعطيل الحفظ التلقائي أو مسح السجل. من المعاينة يمكنك اختيار مسودة مرجعية لعرض النصّين، أو فتح مسودة محفوظة وإلحاقها بالمحرّر. هذا سجل مسودات التوليد، وليس تاريخ تحرير المستند بالكامل.

يدعم حقل ذاكرة القصة استيراد معاينة محلية قصيرة من EPUB غير محمي (حتى 3000 وحدة UTF-16). الاستيراد يقرأ صفحات HTML المتاحة بترتيب الأرشيف ضمن حدود القراءة، ولا يبني فهرس الكتاب أو يتتبّع ترتيب الفصول من ملف الـ spine. تُعرض المعاينة للتحرير ولا تُحفظ أو تُرسل تلقائياً.

يمكن أيضاً استيراد مقتطف من أول خمس صفحات من PDF نصي غير مشفّر (حتى 8 MiB للملف، و3000 وحدة UTF-16 للمقتطف). لا يتضمن الاستيراد OCR للملفات الممسوحة ضوئياً. تُعرض النتيجة في حقل الملاحظات ولا تُحفظ أو تُرسل تلقائياً.

لفهرسة كتاب كامل، افتح **فهرس القصة على البوابة** من نافذة توليد المشهد واختر **تجهيز نص كتاب PDF للفهرسة**. يستخرج التطبيق محليًا النص القابل للاستخراج من كل الصفحات (PDF نصي غير مشفّر حتى 8 ميبيبايت و300 صفحة، دون OCR). لا يُرسل النص قبل تأكيد الاستبدال، وتُرسل الأجزاء إلى البوابة التي تستخدم مزوّد التضمينات. إذا تجاوز النص سعة الفهرس، يُرفض التجهيز بدل اقتطاع الكتاب.

يدعم الخيار **تجهيز نص كتاب EPUB للفهرسة** كتب EPUB النصية غير المحمية، بترتيب القراءة (`spine`) بدل ترتيب ملفات ZIP. الحد 16 ميبيبايت مضغوطة، و32 ميبيبايت بعد الفك، و4 ميبيبايت لكل مستند نصي. ينطبق عليه التأكيد والاستئناف نفسيهما.

الاستبدال غير ذري: يُحذف الفهرس السابق أولًا وقد يبقى الفهرس الجديد جزئيًا عند توقف الرفع. اختر **متابعة رفع الأجزاء المتبقية** لإعادة محاولة الجزء غير المؤكد ومواصلة الرفع دون حذف ما اكتمل. تتاح المتابعة ما دامت النافذة مفتوحة.


يمكن إرسال الملاحظات الظاهرة صراحةً لاستخراج الشخصيات والأحداث عبر المحرك السحابي بعد الموافقة. راجع الاقتراح وعدّله أو تجاهله؛ لا يستبدل الحقل إلا بإجراء صريح ولا يُحفظ تلقائياً.

عند تفعيل إرفاق الملاحظات، يمكنك اختيار **إرسال المقتطفات المطابقة فقط**. يبحث التطبيق محلياً عن تطابق الكلمات مع وصف المشهد ويعرض ما سيرسل (حتى ثلاثة مقتطفات ومجموع 900 وحدة UTF-16). لا يرسل الملاحظات عند غياب المطابقة في هذا الوضع. هذه ليست فهرسة متجهية أو بحثاً دلالياً.

يتوفر انتقاء دلالي اختياري داخل نافذة المشهد: زر **إرسال الوصف والملاحظات للانتقاء الدلالي** يرسل الوصف والملاحظات المعروضة إلى المزوّد بعد الموافقة السحابية. يختار النموذج معرّفات مقتطفات فقط؛ يعرض التطبيق النص الأصلي المختار قبل التوليد. لا يستخدم هذا الخيار فهرساً متجهياً ولا يفهرس الكتب كاملة.

### فواتير البوابة

يدعم نشر البوابة الخاص إصدار فواتير Stripe يدويًا عبر واجهة المشرف. من **الإعدادات ← فواتير البوابة** يمكن للمستخدم عرض فواتير حسابه وتحديث حالتها وفتح صفحة Stripe للدفع أو ملف PDF. لا يستقبل التطبيق بيانات البطاقة. فعّل الموافقة السحابية واحفظ عنوان البوابة بصيغة HTTPS ورمز حسابك في قسم مفاتيح API؛ لا يلزم تغيير محرك التوليد المحلي. اضغط **عرض الفواتير**، ثم استخدم **تحديث الفواتير وحالة الدفع** بعد العودة من Stripe. راجع [إعداد الفوترة والاختبار](services/ai-gateway/README.md#إصدار-الفواتير-وتحصيل-المدفوعات).

### النموذج العصبي المحلي

من **المحركات ← النموذج العصبي على الجهاز**، استورد حزمة MediaPipe LLM نصية متوافقة بصيغة `.task` من مصدر موثوق، ثم اختر **محلي عصبي** للتوليد العام. يمكن اختبار التوليد من شاشة التحليل أو من نافذة توليد مشهد، حتى مع تعطيل الموافقة السحابية أو تفعيل وضع الطيران.

لا يضم التطبيق أوزان نموذج أو ينزّلها تلقائيًا. يلزم جهاز Android ‏ARM64 بذاكرة ومساحة كافيتين، وحزمة يدعمها MediaPipe على الجهاز (الحد 4 جيبيبايت). تُخزّن الحزمة في مساحة التطبيق الخاصة المستثناة من النسخ الاحتياطي ويمكن إزالتها من الشاشة نفسها. قد تختلف جودة العربية حسب الحزمة. هذا المحرك نصي فقط؛ الفهرسة على البوابة وتحليل الصور يستخدمان مسارات منفصلة.

### البحث على الإنترنت

من محرّر موجّه محفوظ، اختر **البحث على الإنترنت**، واكتب عبارة البحث واضغط **إرسال عبارة البحث**. يلزم تفعيل الموافقة السحابية وضبط عنوان البوابة ورمز الحساب في إعدادات OpenAI-compatible، لكن يمكن أن يبقى محرك التوليد محليًا. ترسل البوابة عبارة البحث فقط إلى Brave Search، ولا ترسل نص المحرّر أو ملاحظات القصة. تُعرض النتائج مع روابط تُفتح في المتصفح عند اختيارها، ولا تُضاف إلى التوليد تلقائيًا. راجع [إعداد البحث في البوابة](services/ai-gateway/README.md#البحث-الاختياري-على-الإنترنت).

### تحليل الصور محليًا

في **تحليل صورة واجهة**، اختر **محلي دون اتصال** (الخيار الافتراضي) وحمّل صورة بحجم لا يتجاوز 5 ميبيبايت. تستخدم الميزة نماذج ML Kit المضمّنة لاستخراج تسميات بصرية عامة وتوزيع كتل النص اللاتيني، وتستخرج الألوان الغالبة من الصورة محليًا. لا ترفع الصورة ولا تحتاج إلى موافقة سحابية أو مفتاح. لا يتعرّف هذا الوضع على النص العربي أو على الأزرار والحالات الدلالية للواجهة، ولا يعرض النص المقروء. يبقى Gemini خيارًا منفصلًا يتطلب موافقة صريحة.

### تشغيل سكربت حسابي محلي

من محرّر موجّه محفوظ، اضغط **تشغيل سكربت حسابي محلي**. اكتب تعليمة واحدة لكل سطر: `let` لتعريف متغيّر و`print` لعرض قيمة. يدعم المفسّر الأعداد العشرية والعمليات `+ - * /` والأقواس والتعليقات التي تبدأ بـ`#`. مثال:

```text
let subtotal = 12.5 * 3
print subtotal + 2
```

النتيجة `39.5`. التشغيل محلي ومحدود بـ4096 وحدة UTF-16 و64 سطرًا. لا يدعم لغات البرمجة العامة أو أوامر النظام، ولا يصل إلى الشبكة أو الملفات. لا ينفّذ نص الموجّه تلقائيًا ولا يغيّره.

### التحقق من واجهة Android

شغّل `gradle testDebugUnitTest assembleDebug`، ثم جرّب نسخة `debug` بنافذة ضيقة وأخرى عريضة. تحقق من ظهور شريط التنقل السفلي في العرض الضيق والجانبي في العرض العريض، ومن إمكانية تمرير تبويبات النتيجة والوصول إلى كل الأزرار. جرّب تكبير الخط والوضع الداكن وTalkBack، وراجع أن النص المختلط (مثل رقم فاتورة مع وصف عربي) يبقى مقروءًا. في المشاريع، جرّب إنشاء مشروع وأرشفته واستعادته؛ في الفواتير، تحقّق من حالة الفراغ وإعادة المحاولة بعد انقطاع الاتصال.

لتشغيل التطبيق محليًا، افتح جذر المستودع في Android Studio، وثبّت **Android SDK 35**، واضبط Gradle على **JDK 17**، ثم نفّذ **Sync Project with Gradle Files** وشغّل الوحدة `app` على محاكي أو جهاز Android. من الطرفية، عند توفر Gradle 8.9 وجهاز متصل، شغّل `gradle installDebug`. لا يحتوي المستودع على مشغّل `gradlew`.

في شاشة **المشاريع**، يفتح زر **جديد** نموذج الإنشاء، ويفتح زر **تعديل المشروع** النموذج نفسه مع البيانات الحالية. التعديل يحفظ الاسم والوصف فقط دون تغيير حالة التثبيت أو الأرشفة. يطلب زر **حذف المشروع** تأكيدًا قبل التنفيذ.
