# Forgeprom Code Studio

**استوديو عربي لصياغة الموجزات (البرومبتات) الهندسية الاحترافية** — حوّل فكرتك العربية الحرة إلى موجه هندسي كامل جاهز للنسخ في منصات بناء الكود (Claude، ChatGPT، Cursor، Replit…).

تطبيق **Android أصلي** (Kotlin + Jetpack Compose + Material 3)، يعمل **محلياً دون إنترنت** بمحرك قاعدي عربي، مع محركات سحابية **اختيارية بموافقة صريحة**.

## الميزات (سجل صادق)

| الميزة | الحالة |
|---|---|
| واجهة عربية RTL + وضع فاتح/داكن | ✅ جاهز |
| تحليل الفكرة العربية (نية، ميزات، متطلبات، افتراضات معلنة، أسئلة ≤3) | ✅ جاهز — محلي دون إنترنت |
| توليد برومبت 12 قسماً (عربي / إنجليزي / ثنائي) | ✅ جاهز |
| فحص جودة 14 عنصراً + إصلاح تلقائي | ✅ جاهز |
| النقد والاقتراح (نقاط قوة/نواقص/مخاطر) | ✅ جاهز |
| إدارة المشاريع (إنشاء/تثبيت/أرشفة/حذف) + محرر موجزات | ✅ جاهز |
| تصدير TXT / MD / JSON + نسخ ومشاركة (UTF-8) | ✅ جاهز |
| تحليل صور الواجهات (Gemini Vision) | ✅ سحابي اختياري بموافقة — غير متاح محلياً بصدق |
| محرك محلي قاعدي دون إنترنت | ✅ جاهز |
| نموذج عصبي محلي على الجهاز | ⏳ قيد التكامل لاحقاً |
| تشغيل الكود داخل المحرر | ⏳ مؤجل بدواعٍ أمنية |

**مبدأ الصدق:** لا تُعلن ميزة جاهزة قبل عملها فعلياً. الموافقة على السحابة **مرفوضة افتراضياً** — لا يغادر أي محتوى جهازك دون موافقتك الصريحة.

## البدء السريع

```bash
git clone https://github.com/malkbaty7-sketch/forgeprom-app.git
cd forgeprom-app
gradle assembleDebug     # أو افتح المشروع في Android Studio (JDK 17)
```

- متطلبات البناء: JDK 17، Gradle 8.9، AGP 8.5.2، Kotlin 2.0.20، compileSdk 35، minSdk 26.
- الخرج: `app/build/outputs/apk/debug/app-debug.apk`.
- الاختبارات: `gradle testDebugUnitTest` (8 اختبارات لطبقة المجال).

## البناء التلقائي (CI)

يرفع كل دفعة إلى `main` إلى سير عمل GitHub Actions (`.github/workflows/android.yml`):
1. `testDebugUnitTest` — اختبارات طبقة المجال.
2. `assembleDebug` — بناء APK.
3. رفع الناتج كـ artifact باسم **forgeprom-debug-apk** — نزّله من تبويب Actions.

## البنية

- `domain/` — محلل الأفكار، مولد البرومبت، فحص الجودة، النقد (Kotlin نقي قابل للاختبار).
- `core/` — المحركات (محلي قاعدي + Gemini + متوافق OpenAI)، Room، الإعدادات، مفاتيح مشفّرة، التصدير.
- `ui/` — Compose: شاشات الرئيسية/التوليد/التحليل/النتيجة/الصور/المشاريع/المحرر/المحركات/الإعدادات.
- `docs/` — الخطة، PRD، المعمارية، سجل التغييرات.

## الخصوصية

- كل شيء يعمل محلياً افتراضياً (المحرك القاعدي لا يحتاج إنترنت).
- مفاتيح API تُحفظ مشفّرة (EncryptedSharedPreferences).
- أي استدعاء سحابي (Gemini / OpenAI) محجوب خلف بوابة موافقة صريحة.

### تجربة المخرج التفاعلي (MVP)

من محرر موجه محفوظ، ظلّل جزءاً من النص واضغط **تعديل ذكي**. اكتب توجيهاً مثل «أضف صوت المطر»، وراجع الاقتراح قبل تطبيقه على التحديد فقط. لا يُحفظ التغيير في المشروع حتى تضغط **حفظ**.

تتطلب التجربة تفعيل الموافقة السحابية من الإعدادات، وضبط Gemini أو مزوّد OpenAI-compatible جاهز كمحرك للتوليد العام من شاشة النماذج. لا يرسل التطبيق عنوان الموجه. السياق المحيط معطّل افتراضياً؛ عند تفعيله يُعرض ما سيُرسل، بحد أقصى 400 وحدة UTF-16 لكل جانب. لا يتوفر توليد بديل بالمحرك المحلي.

لاختبار التجربة يدوياً: جرّب الطلب دون موافقة، ثم بعد تهيئة مزوّد سحابي؛ تحقّق من أن الإلغاء لا يغيّر النص وأن التطبيق يستبدل التحديد فقط، ثم احفظ وأعد فتح المحرر. اختبارات طبقة المجال: `gradle testDebugUnitTest`.

تتضمن نافذة التعديل إجراءات جاهزة للغضب ووجهة النظر والصوت والاختصار وتوسيع الحوار. اختيار الإجراء يملأ التوجيه فقط؛ يمكنك تعديله قبل الإرسال. تعرض المعاينة النص الأصلي والمقترح كاملين، ويمكنك الرجوع لتعديل التوجيه دون تغيير المستند.

إذا فشل طلب التعديل، يمكنك إعادة المحاولة بالتوجيه نفسه. بعد تطبيق الاقتراح، يعيد زر **تراجع عن التعديل الذكي** النص والتحديد السابقين ما دمت لم تعدّل النص يدوياً أو تغادر المحرر.

### توليد مشهد وذاكرة القصة المحلية

في محرر موجه محفوظ، افتح **توليد مشهد وذاكرة القصة**. اكتب وصفاً للمشهد، وأضف ملاحظات الشخصيات أو الأحداث يدوياً. زر حفظ الملاحظات يخزنها على الجهاز لهذا الموجه؛ لحذفها امسح الحقل واحفظه. لا تُرفق الملاحظات بطلب التوليد إلا عند اختيار إرسالها، ولا يُرسل محتوى المحرر. يلزم تفعيل الموافقة السحابية وضبط محرك التوليد العام.

بعد التوليد، راجع المشهد ثم شاركه بصيغة `.fountain` أو ألحقه بنهاية المحرر. الإلحاق قابل للتراجع قبل التعديل اليدوي، ولا يُحفظ المستند إلا عبر زر **حفظ**. يتحقق التطبيق مبدئياً من عنوان المشهد ووجود محتوى ومن عدم وجود أسوار Markdown؛ لا يجري تحققاً شاملاً من صيغة Fountain. لا يشمل هذا الإصدار استيراد الكتب، أو الاسترجاع الدلالي.

يدعم العرض أيضاً تصدير **FDX** للمشهد المولّد. يحوّل المصدّر عنوان المشهد والوصف وأسماء الشخصيات وإشارات الأداء والحوار إلى فقرات XML؛ لا يدعم كل امتدادات Fountain أو خصائص مستندات Final Draft الكاملة.

يتوفر كذلك PDF نصي للمشهد من المعاينة، مع التفاف الأسطر وتعدد الصفحات باستخدام محرك النص في Android.

تتضمن نافذة التوليد لوحة مصغرة لضبط الإيقاع والجو وتوجيهات الكاميرا والصوت. من المعاينة يمكنك حفظ نسخة محلية صراحةً؛ يحتفظ السجل بآخر خمس مسودات محفوظة لهذا الموجّه ويمكن إعادة فتحها أو مسح السجل. هذا ليس سجل مراجعات تلقائياً للمستند.

تشمل لوحة المخرج أيضاً اختيار أسلوب الإخراج والإضاءة وتفعيل إشارات الأداء. تُطبّق هذه الخيارات على مسودة السيناريو التالية ولا تغيّر أي مسودة محفوظة.

قبل التوليد، اختر صيغة المشهد: **سيناريو** (Fountain وFDX)، أو **سرد سينمائي**، أو **قائمة لقطات** (TXT). يتوفر PDF للثلاثة. تُحفظ المسودات بصيغتها النصية في السجل المحلي.

يُحفظ آخر خمسة مخرجات مختلفة تلقائياً لهذا الموجّه عند نجاح التوليد، ويمكن تعطيل الحفظ التلقائي أو مسح السجل. من المعاينة يمكنك اختيار مسودة مرجعية لعرض النصّين، أو فتح مسودة محفوظة وإلحاقها بالمحرّر. هذا سجل مسودات التوليد، وليس تاريخ تحرير المستند بالكامل.

يدعم حقل ذاكرة القصة استيراد معاينة محلية قصيرة من EPUB غير محمي (حتى 3000 وحدة UTF-16). الاستيراد يقرأ صفحات HTML المتاحة بترتيب الأرشيف ضمن حدود القراءة، ولا يبني فهرس الكتاب أو يتتبّع ترتيب الفصول من ملف الـ spine. تُعرض المعاينة للتحرير ولا تُحفظ أو تُرسل تلقائياً.

يمكن أيضاً استيراد مقتطف من أول خمس صفحات من PDF نصي غير مشفّر (حتى 8 MiB للملف، و3000 وحدة UTF-16 للمقتطف). لا يتضمن الاستيراد OCR للملفات الممسوحة ضوئياً. تُعرض النتيجة في حقل الملاحظات ولا تُحفظ أو تُرسل تلقائياً.

لفهرسة كتاب كامل، افتح **فهرس القصة على البوابة** من نافذة توليد المشهد واختر **تجهيز نص كتاب PDF للفهرسة**. يستخرج التطبيق محليًا النص القابل للاستخراج من كل الصفحات (PDF نصي غير مشفّر حتى 8 ميبيبايت و300 صفحة، دون OCR). لا يُرسل النص قبل تأكيد الاستبدال، وتُرسل الأجزاء إلى البوابة التي تستخدم مزوّد التضمينات. إذا تجاوز النص سعة الفهرس، يُرفض التجهيز بدل اقتطاع الكتاب.

يدعم الخيار **تجهيز نص كتاب EPUB للفهرسة** كتب EPUB النصية غير المحمية، بترتيب القراءة (`spine`) بدل ترتيب ملفات ZIP. الحد 16 ميبيبايت مضغوطة، و32 ميبيبايت بعد الفك، و4 ميبيبايت لكل مستند نصي. ينطبق عليه التأكيد والاستئناف نفسيهما.

الاستبدال غير ذري: يُحذف الفهرس السابق أولًا وقد يبقى الفهرس الجديد جزئيًا عند توقف الرفع. اختر **متابعة رفع الأجزاء المتبقية** لإعادة محاولة الجزء غير المؤكد ومواصلة الرفع دون حذف ما اكتمل. تتاح المتابعة ما دامت النافذة مفتوحة.


يمكن إرسال الملاحظات الظاهرة صراحةً لاستخراج الشخصيات والأحداث عبر المحرك السحابي بعد الموافقة. راجع الاقتراح وعدّله أو تجاهله؛ لا يستبدل الحقل إلا بإجراء صريح ولا يُحفظ تلقائياً.

عند تفعيل إرفاق الملاحظات، يمكنك اختيار **إرسال المقتطفات المطابقة فقط**. يبحث التطبيق محلياً عن تطابق الكلمات مع وصف المشهد ويعرض ما سيرسل (حتى ثلاثة مقتطفات ومجموع 900 وحدة UTF-16). لا يرسل الملاحظات عند غياب المطابقة في هذا الوضع. هذه ليست فهرسة متجهية أو بحثاً دلالياً.

يتوفر انتقاء دلالي اختياري داخل نافذة المشهد: زر **إرسال الوصف والملاحظات للانتقاء الدلالي** يرسل الوصف والملاحظات المعروضة إلى المزوّد بعد الموافقة السحابية. يختار النموذج معرّفات مقتطفات فقط؛ يعرض التطبيق النص الأصلي المختار قبل التوليد. لا يستخدم هذا الخيار فهرساً متجهياً ولا يفهرس الكتب كاملة.

### فواتير البوابة

يدعم نشر البوابة الخاص إصدار فواتير Stripe يدويًا عبر واجهة المشرف. من **الإعدادات ← فواتير البوابة** يمكن للمستخدم عرض فواتير حسابه وتحديث حالتها وفتح صفحة Stripe للدفع أو ملف PDF. لا يستقبل التطبيق بيانات البطاقة. راجع [إعداد الفوترة والاختبار](services/ai-gateway/README.md#إصدار-الفواتير-وتحصيل-المدفوعات).
